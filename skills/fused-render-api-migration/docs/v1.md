# fused API version 1 — over version 0

**Date:** 2026-09-02. **Summary:** `fused.ai` becomes a namespace; one options object and one result frame on every AI verb; `provider` on every verb.

The `fused.ai` API was rebuilt as one learn-once surface. Nothing outside `fused.ai` (and its Python twin `fused_ai`) changed in this version — `fused.runPython`, `fused.params`, file IO, capture, jobs are untouched.

## What changed

**`fused.ai` is a NAMESPACE, not a function.** `fused.ai(prompt)` and `fused.ai.text(prompt, opts)` are gone (removed, not aliased). Text is `fused.ai.text({prompt, ...opts})` — one options object, like image/video/transcribe/embed.

**`provider` on every verb.** Every verb takes an optional `provider: "local" | "claude"`, and every reply carries `provider` back. Omitted: text → Claude (default-model pref or haiku); the other four → local. `provider: "claude"` with a local repo id is a 400; `provider: "claude"` on image/video/transcribe/embed is a 409 `unavailable`.

**One result frame.** Every verb resolves with

```
{ provider, finishReason, warnings, usage,
  response: { id, modelId, timestamp },
  providerMetadata: { <provider>: {...} },
  ...payload }
```

plus a single verb-named payload:

| verb | payload |
|---|---|
| text | `text` |
| image | `images: [{path, url, mediaType}]` |
| video | `videos: [{path, url, mediaType}]` |
| transcribe | `text`, `segments: [{text, startSecond, endSecond, speaker?, words?}]`, `language`, `durationInSeconds` |
| embed | `embeddings: number[][]`, `values` |

There is **no top-level `model`** (read `response.modelId`) and **no echoed inputs** at top level: the server's snapped/invented values (seed, size, steps, transcript file paths, seconds) live under `providerMetadata[provider]`. `usage` is camelCase: `inputTokens / outputTokens / totalTokens`. `finishReason` is `stop | length | cancelled`.

**Inputs are learn-once too.** Unknown options are a **400 naming the option** on every verb, text included — nothing is silently dropped any more. `onChunk` is the ONE partial-result callback on every streaming verb (a string on text, a segment on transcribe); transcribe's `onSegment` is gone. Text `images` resolve beside the calling page like every other file input. `abortSignal` (a standard `AbortSignal`) is accepted on every verb; it rejects `cancelled`. Sampling knobs the Claude tier lacks (`temperature`, `maxTokens`, `topP`) no longer 400 — they are dropped and reported in `warnings[]` as `{type: "unsupported-setting", setting, message}`.

**Wire.** Direct `/api/ai` calls are camelCase: `systemPrompt`, `maxTokens`, `topP` (were `system_prompt`, `max_tokens`, `top_p`).

**Python.** `fused_ai.text(...)`, `.image(...)`, `.transcribe(...)`, `.embed(...)` take `provider=` and return the same frame as a dict.

## Checklist — old → new

- `fused.ai(prompt)` / `fused.ai.text(prompt, opts)` → `fused.ai.text({prompt, ...opts})`
- `res.model` → `res.response.modelId` (all five verbs)
- `usage.input_tokens / output_tokens` → `usage.inputTokens / outputTokens / totalTokens`
- image `res.url / seed / width / height / steps / …` → `res.images[0].url`, `res.providerMetadata.local.seed / …`; there is no `previewUrl` on the result
- video `res.url` → `res.videos[0].url`
- transcribe `res.duration / output / url / outputText / speakers / estimatedSpeakers` → `durationInSeconds` + `providerMetadata.local.*`; segment and word `start / end` → `startSecond / endSecond` (inside the chunk callback too)
- embed `vectors / dim` → `embeddings` + `providerMetadata.local.dim`; `values` added
- transcribe `onSegment` → `onChunk`
- any option the verb does not document → remove it (400 now)
- direct `/api/ai` bodies: `system_prompt / max_tokens / top_p` → `systemPrompt / maxTokens / topP`
- Python: readers of `fused_ai.*` results → `["text"]`, `["response"]["modelId"]`, `["usage"]["inputTokens"]`, `["images"][0]["url"]`, …

## Grep for leftovers

`fused.ai(`, `.input_tokens`, `.output_tokens`, `onSegment`, `system_prompt`, `max_tokens`, `top_p`, `.previewUrl`, `estimatedSpeakers`, `.vectors`, `res.model`, `.duration` (on a transcribe result).
