# Twitch creator dashboard stats
trigger: my twitch stats, twitch analytics, stream summary, twitch revenue, my channel analytics, how did my stream do, twitch dashboard, subscriber count

1. goto https://dashboard.twitch.tv/u/<my channel>/analytics/channel (Insights > Channel Analytics in the left sidebar). If a sign-in page or 2FA appears, use `login`. If the channel login is unknown, click the avatar at the top right and `read` the name.
2. Set the date range the task names with the picker at the top (default: last 30 days) and `read` the summary tiles: average viewers, max viewers, live views, unique viewers, follows, new subscriptions, hours watched, time streamed.
3. `read` the "Stream summary" list (Insights > Stream Summary, or the recent streams table) for the last 5 streams: date, length, average viewers, peak viewers, new follows, chatters.
4. goto https://dashboard.twitch.tv/u/<my channel>/analytics/revenue (Insights > Revenue) only if the task asks about money; `read` the period total and the breakdown: subscriptions, Bits, ads, and the next payout line. Quote amounts exactly; change no payout settings.
5. goto https://dashboard.twitch.tv/u/<my channel>/community/subscribers if subscriber detail is asked; `read` the count by tier and the gifted total.
6. Report the period tiles as a table with the change versus the previous period if the page shows it, the last 5 streams as a table, and the revenue breakdown if requested. `save` the stream table as twitch-streams.csv when more than 5 rows are requested.
