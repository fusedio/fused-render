02 Privacy

Your data never goes looking for a server.

Not a promise — an architecture. The app is a local process reading local files. Here is every wire that exists, and what has to happen before one is used.

Never leaves your machine

  • Your filesOpened in place from your disk. Nothing is uploaded in order to be read, previewed, queried or mapped.
  • Local model inferenceEvery prediction is computed on your own hardware. No request goes out to produce one.
  • The tools you buildPlain .html and .py files in a folder you chose — not rows in our database.
  • What you do with itNo account to create, and no analytics or usage tracking built into the app.

Uses the network, when you ask

  • Downloading a modelFetched once from Hugging Face, then it is yours offline forever.
  • Claude writing a toolClaude Code is Anthropic’s hosted service, so building talks to the cloud — on your own Claude subscription, billed by Anthropic, never by us. Running the finished tool does not.
  • Checking for a new versionA release lookup against GitHub. That is the whole of it.

— Help

Troubleshooting

Something not working? Pick what’s happening on the left — the fix is on the right.

The error you'll see

Invalid API key · Please run /login

What happened

Fused Render uses Claude on your computer to build things. Claude is installed, but it isn't signed in to your account yet — so nothing can run.

How to fix it

  1. Open the Terminal app: press ⌘ Space, type Terminal, press Return.
  2. Type claude and press Return.
  3. Type /login and press Return. Your browser opens — sign in with your Claude account (the same one you use at claude.ai).
  4. Come back to Fused Render and start a new chat.

Signed in — you're done here

The error you'll see

Claude Code isn't installed (or couldn't be found)

What happened

Fused Render needs a free helper called Claude Code to build things, and it couldn't find it on this Mac. Either it was never installed, or it's somewhere the app can't see.

How to fix it

  1. Install Claude Code from claude.com/claude-code.
  2. Check it worked: open Terminal (⌘ Space, type Terminal), type claude, press Return. It should start.
  3. Quit Fused Render and open it again.
Terminal
claude
Claude starts — Fused Render will find it now

The error you'll see

Your Claude plan's usage limit was reached

What happened

Your Claude plan includes a set amount of use, and you've used it up for now. Nothing is broken — you just have to wait.

How to fix it

  1. Wait for your limit to reset — the error message tells you when.
  2. In a hurry? Upgrade your plan at claude.ai.
  3. Nothing to change in Fused Render — try again after the reset.

The error you'll see

Error: something long and technical…

What happened

The app ran into a problem it doesn't have a friendly explanation for, so it showed the technical message as-is. Usually it's really one of the other three issues underneath.

How to fix it

  1. Check the sign-in and install fixes above — they clear most of these.
  2. Start a new chat in Fused Render and try again.
  3. Still stuck? Tell us here and paste the exact error text — we'll help.
