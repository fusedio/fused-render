# LinkedIn feed digest
trigger: linkedin feed, my linkedin, feed digest, what's new on linkedin, linkedin this morning, catch up on linkedin, linkedin posts today

1. goto https://www.linkedin.com/feed/ and `wait` for the first post. If a sign-in page, 2FA or "quick security check" captcha appears, use `login`. Close the Messaging overlay (its chevron at bottom right) and any "Try Premium" dialog with Escape.
2. Click the "Sort by" dropdown above the first post and pick "Recent" (the default is "Top") unless the task asks for top posts.
3. Scroll down 4 times. On each screen note author, headline, first lines, reactions and comment count. Skip anything labelled "Promoted" or "Suggested". Click "…more" on long posts that match the task, then `read` the post.
4. Pick 8 posts: those on the task's topics, else the 8 with the most reactions from 1st-degree connections.
5. For the top 2, click the comment count and `read` the first screen of comments for the strongest reply.
6. Report 8 bullets: author and headline, one-line gist, reactions and comments, link (the post's timestamp link; open it and `back` only if the href is not in the element list). Group by topic if more than three topics appear. If the user asked for more than 10 posts, `save` the full list as linkedin-feed.md and keep the chat to the top 5.
