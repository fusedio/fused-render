# Apple Notes read or summarize a note
trigger: summarize my note, read my note, what does my note say, open the note, notes called, my note titled, from my notes

1. goto https://www.icloud.com/notes/ and `wait` for the folder list. If a sign-in, 2FA or trust page appears, use `login`.
2. Find the note: click its folder if the task names one, else search its title in the search field; click the note in the list.
3. `read` the editor pane for the full body; scroll it if the note is long and `read` again. Note checklists (checked and unchecked items), tables, headings and attachments (images show as attachment thumbnails; describe their names, not their contents).
4. If the task asks for several notes (a folder's worth), open at most 6 and `read` each.
5. Report: the summary the task asked for, then the note's key items as bullets (open checklist items first), the folder and last-edited date. For a long note or several notes, `save` the full text as notes.md and keep the chat answer short.
