# Linkme page audit
trigger: my linkme, check my links, audit my bio page, linkme page, link in bio audit, are my bio links working, linkme audit

1. goto https://linkme.bio/dashboard; if a sign-in page, 2FA or captcha appears, use `login`. If the account has several bios, open the one the task names (default: the first). Dismiss any upgrade-to-PRO banner.
2. In the Links section (Portuguese label "Links") `read` every block in order: title, destination URL, type (link, product, WhatsApp button, digital product), on or off, and any schedule dates. Do not drag, toggle or edit anything.
3. goto the public page https://linkme.bio/<username> (the address shown at the top of the dashboard) and `read` it to confirm which blocks are actually visible and in what order.
4. For the top 10 visible links, open each URL with tab new, `wait` for it to load, `read` the first screen, then tab close. Note 404s, redirects to a different site, pages that say sold out or ended, and promos whose title carries a past date.
5. Report the blocks in order as a table: title, URL, on/off, status (ok / broken / redirect / stale), then a short list of suggested fixes (broken first, then stale, then duplicates), plus the public page link. Change nothing; if the user wants fixes applied, `offer` to do them one at a time with approval.
