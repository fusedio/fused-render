# Apple Notes open checklists and to-dos
trigger: my to-do notes, unchecked items, open checklist, what's left on my list, checklist in notes, shopping list note, todo in notes

1. goto https://www.icloud.com/notes/ and `wait` for the folder list. If a sign-in, 2FA or trust page appears, use `login`.
2. Search the note list for the list's name from the task (for example "shopping", "packing", "todo"); if the task names no list, search "checklist" and also `read` the last 10 recently edited notes' previews for circle bullets.
3. Open at most 5 candidate notes and `read` each body; checklist rows show as checked or unchecked items.
4. Count checked versus unchecked per note and copy the unchecked items verbatim.
5. Report each list with its folder, done/total count, and the open items as bullets. Do not check anything off; if the task asks to, show the exact items to tick and proceed only after approval.
