# LTK find a product and its rate
trigger: ltk link for, link this on ltk, find on ltk, ltk commission for, product on ltk, does ltk have, ltk rate for, add to my ltk folder

1. goto https://creator.shopltk.com; if a sign-in page, 2FA or captcha appears, use `login`. Open the Products menu and its product search (beside "My Folders"). The bookmarklet under Tools > LTK Product Link only works from a bookmarks bar, so use the in-dashboard search.
2. Type the product name (or paste the retailer URL) and submit; `read` the top 10 results: product, retailer, price, and the commission tier or rate shown (High is 11% or more, Medium 7-11%, Low 7% or less, or an exact percentage).
3. If several retailers carry it, `read` each one's rate and pick the best-paying unless the task names a retailer. Open that retailer's product page with tab new, `read` price and availability, tab close.
4. Check Products > "My Folders" for an existing saved copy so you do not duplicate it; note the folder name if found.
5. Only if the task asks: click the heart / save and add it to the folder the task names, or copy the link. Do not add it to a post or publish. Otherwise leave nothing saved.
6. Report: product, retailer, price, stock, commission tier or rate, the LTK link or folder if asked, and the alternatives as a table (retailer, rate, price). If it is not linkable on LTK, say so and name the closest linkable retailer. `remember` where the product search lives once you have found it.
