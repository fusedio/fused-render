Google Docs Tabs — create and fill tabs in your Google Docs by telling it what you want.

One-time setup: give the app a Google service account

The app writes to Google Docs as a service account, a robot Google identity with its own email. You create it once, paste its key here, and then share any doc you want the app to edit with that email, exactly like sharing with a colleague. No sign-in pop-ups. The key is stored in this app's .fused/data folder and never packed or shared.

  1. Open Google Cloud Console → Google Docs API and click Enable (create a project if asked).
  2. Go to IAM & Admin → Service accounts → Create service account (any name; no roles needed) → Done.
  3. Open the new account → Keys → Add key → Create new key → JSON. A key file downloads.
  4. Paste the contents of that file below.
