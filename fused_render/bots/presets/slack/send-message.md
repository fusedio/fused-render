# Slack draft and send a message
trigger: send a slack message, message on slack, reply on slack, dm on slack, tell on slack, slack reply, post to the channel

1. Only do this when the task plainly asks to send; otherwise stop and `ask`. If an APP TOOL for Slack is listed, use it instead of the steps below.
2. goto https://app.slack.com/client and `login` if a sign-in page, workspace picker, 2FA or captcha appears. Press Ctrl+K (Cmd+K on Mac), type the channel or person name, press Enter, and confirm the header shows the right channel or person.
3. If the task is a reply to a specific message, find it (scroll, or search with from:@name plus a few words) and click "Reply in thread" on it so the composer belongs to the thread, not the channel.
4. `read` the last 10 messages so the wording fits the conversation and does not repeat an answer already given.
5. Click the message box and type the text without submit (Shift+Enter for a new line). Do not press Enter.
6. Stop here: show the user the destination (channel or person, thread or not) and the exact text in the box, and proceed only after approval. On approval press Enter to send. If the user wants changes, select the text in the box, retype, and show it again.
7. Report where it was sent, the text, the time, and the permalink (the href of the sent message's timestamp). If approval was refused, clear the box and report that nothing was sent.
