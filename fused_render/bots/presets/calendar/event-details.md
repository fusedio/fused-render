# Google Calendar event details and RSVPs
trigger: who accepted, who is coming, rsvps for, who declined, guest list, event details, find the event, meeting link for

1. goto https://calendar.google.com/calendar/u/0/r/search?q=<event name or keyword> (`login` if a sign-in page, 2FA or captcha appears). The search page lists matching events, past and future, with date and time.
2. `read` the result list. If the task names a date, pick the event on that date; otherwise pick the next upcoming one. If nothing matches, retry with one distinctive word, then with the organiser's name; stop after 3 searches.
3. Click the event and `read` the detail panel: date and time, location, Google Meet or other video link, description, attachments, organiser, and the guest list with the Yes / No / Maybe / Awaiting counts. Click the guest count or "Show more" if the list is folded.
4. For a recurring series, open the same event on at most 2 further dates, because responses differ per instance; say which date each count belongs to.
5. If the task asks to accept, decline or answer "maybe", do not click the RSVP buttons yet: stop, show the user the event and the reply that will be sent, and click only after approval. Never use "Propose a new time" unless the task says so.
6. Report: title, when, where or link, organiser, then the names under Yes / No / Maybe / Awaiting with counts, the description in two lines, and the search URL used. For a guest list over 20 names, `save` it as event-guests.md and give counts in the chat.
