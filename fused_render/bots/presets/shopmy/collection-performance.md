# ShopMy collection performance
trigger: which collections perform, collection analytics, shop views, shopmy collection stats, best collection, which shelf sells, shopmy shop analytics, refresh my collections

1. goto https://shopmy.us and open the dashboard; if a sign-in page, 2FA or captcha appears, use `login`. Open "My Shop" (the shop editor).
2. Click "show analytics" at the shop level and `read` shop views for the period the task names (default: last 30 days; set the date range if a selector exists).
3. For each Section, open each collection's analytics ("show analytics") and `read` collection views, item clicks, orders and commission earnings. Cover at most 12 collections; if there are more, take the newest 12 and say so.
4. For the top 3 collections by commission, `read` the item list and note the 3 best products in each (clicks, orders).
5. Click "hide analytics" when done; edit nothing.
6. Report a table sorted by commission: collection, section, views, item clicks, orders, commission, click rate (clicks divided by views); the collections with views but no orders (candidates to refresh); the top products; and the shop link. `save` as shopmy-collections.csv when more than 10 collections.
