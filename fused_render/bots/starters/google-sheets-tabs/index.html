Google Sheets Tabs — read, append to, style and create worksheet tabs in your Google Sheets.

One-time setup: give the app a Google service account

The app reads and writes Google Sheets as a service account, a robot Google identity with its own email. You create it once, paste its key here, and then share any spreadsheet you want the app to use with that email, exactly like sharing with a colleague. The same key works for the Google Docs Tabs app. The key is stored in this app's .fused/data folder and never packed or shared.

  1. Open Google Cloud Console → Google Sheets API and click Enable. For comments, also enable the Google Drive API.
  2. Go to IAM & Admin → Service accounts → Create service account (any name; no roles needed) → Done. Already have one for Google Docs Tabs? Reuse it.
  3. Open the account → Keys → Add key → Create new key → JSON. A key file downloads.
  4. Paste the contents of that file below.
