# Linkme analytics digest
trigger: linkme analytics, link clicks, bio page views, which links get clicked, linkme stats, how is my bio doing, linkme traffic, bio link clicks

1. goto https://linkme.bio/dashboard; if a sign-in page, 2FA or captcha appears, use `login`. Click "Analytics" in the dashboard menu.
2. If the screen says the numbers are sample or example data (the free plan shows a demo; real analytics is PRO), stop and report that; do not quote the demo numbers.
3. Set the period selector to the period the task names (default: last 7 days) and `read` the page: views ("Visualizações"), clicks ("Cliques"), the ranking of most-clicked links, and traffic sources ("De onde vêm suas visitas": Instagram, TikTok, search, QR code, ads). Note any device or country breakdown if shown.
4. Move the selector to the previous period of the same length and `read` the same numbers for comparison.
5. If the task asks for a file and an export button ("Exportar") exists, click it; the download lands in the Inbox folder.
6. Report: views, clicks and click rate (clicks divided by views) with the change versus the previous period; the top 5 links by clicks and any link with zero clicks; the top 3 sources; one concrete reordering suggestion. `save` as linkme-analytics.md when the task covers more than two periods.
