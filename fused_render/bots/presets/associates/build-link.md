# Amazon Associates build an affiliate link
trigger: affiliate link for, associates link, make an amazon link, amazon link with my tag, amzn.to link, build a product link, link to this product

1. goto https://affiliate-program.amazon.com/home/productlinks (Product Linking > Product Links). If a sign-in page appears, use `login`.
2. In the search box type the product name, ASIN or Amazon URL from the task and submit; `read` the result list and pick the exact product (match brand, model and variant; the ASIN from the task's URL is in the /dp/<ASIN> part).
3. Click "Get Link" on that result. If the task names a tracking ID, pick it in the Tracking ID dropdown at the top of the page first (the choice applies to every link built after it).
4. In the link panel choose "Text only" (default) and `read` the full link and the short link (amzn.to) shown. Click "Short Link" if the short form is not visible.
5. For several products, repeat steps 2-4 for at most 8 products.
6. Report each product with its ASIN, price shown, full link and short link, and the tracking ID used. For more than 3 products also `save` them as affiliate-links.md. Never put the links on any site or post unless the task says so.
