# Twitch who is live from my follows
trigger: who is live on twitch, twitch following, live now on twitch, my twitch follows, anyone streaming, twitch live, who's streaming

1. goto https://www.twitch.tv/directory/following/live. If a sign-in page appears, use `login`. Dismiss the cookie banner and any "turn on notifications" prompt.
2. `read` the live channel cards: channel name, stream title, category, viewer count, and the "started N minutes ago" text where shown (hover a card to see it). Scroll twice if the task asks for everyone.
3. If a channel the task names is not live, goto https://www.twitch.tv/<channel>/schedule and `read` the next scheduled stream, then https://www.twitch.tv/<channel>/videos?filter=archives&sort=time for the latest VOD title and date.
4. goto https://www.twitch.tv/directory/following/videos only if the task asks for recent VODs from follows; `read` the first 12 cards.
5. Report the live channels as bullets sorted by viewers: channel, title, category, viewers, link; then any named channel that is offline with its next scheduled time or last VOD.
