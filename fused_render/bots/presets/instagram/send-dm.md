# Instagram send a DM
trigger: dm on instagram, message them on instagram, send instagram message, reply on instagram, instagram dm to, send a dm

1. goto https://www.instagram.com/direct/inbox/ ; on a sign-in page or challenge use `login`. Dismiss Not Now dialogs.
2. For an existing chat click it in the left list and `read` the last 5 messages so the reply fits. For a new one click the pencil (new message) icon at the top of the list, `type` the handle in the "To:" box, click the exact match, then Chat.
3. Draft the message from the task, keeping the user's wording when given. No codes, no links to sites the user did not name.
4. Click the "Message..." box and `type` the text without submit.
5. Stop before sending: show the recipient and the exact text as the risky step. Proceed only after approval; then press Enter and `read` the chat to confirm the message appears.
6. Report: recipient, the text, the time, and the chat link https://www.instagram.com/direct/t/<id>/. If Instagram says the account cannot be messaged or the request will sit in Requests, say so.
