# Amazon Associates tracking ID and link performance
trigger: which links convert, tracking id performance, link type report, clicks per link, associates clicks, best performing affiliate links, which tracking id

1. goto https://affiliate-program.amazon.com/home/reports and set the date range the task names (default: last 30 days). If a sign-in page appears, use `login`.
2. Click the Tracking IDs tab and `read` the table: tracking ID, clicks, ordered items, conversion, shipped items, fees. Sort by fees if the header allows it.
3. Click the Link Type tab and `read` performance by link type (text, image, native shopping ads, SiteStripe, Mobile Popover): clicks, ordered items, conversion.
4. Click the Orders tab and `read` the first 20 rows to see which products the best tracking ID actually sold.
5. If the user wants to compare periods, change the date range to the previous period and `read` the Tracking IDs table again.
6. Report a table of tracking IDs with clicks, conversion and fees (and the change versus the previous period if asked), which link types convert best, and the products behind the top ID. For more than 10 tracking IDs `save` the table as tracking-ids.csv.
