# Apple Notes find a note
trigger: find my note, apple notes, note about, search my notes, icloud notes, which note has, in my notes

1. goto https://www.icloud.com/notes/ and `wait` for the folder list on the left. If the Apple ID sign-in, 2FA or "Trust this browser" page appears, use `login`.
2. Click the search field at the top of the note list (or press Control+F inside the app) and type the words from the task; submit. `read` the result list: note title, folder, date, preview snippet. Read the first 15 results at most.
3. Open the best 3 matches one at a time and `read` the note body in the editor pane; a result's snippet is not the note.
4. If nothing matches, try one synonym and the search once more, then check the "Recently Deleted" folder only if the task suggests the note was lost.
5. Report the matching notes as bullets with title, folder, last-edited date and the passage that answers the task quoted exactly. Note that iCloud Notes has no link per note, so give the title and folder to open it.
