# Apple Notes recent notes digest
trigger: recent notes, what did i write this week, notes from today, latest notes, notes digest, what's new in my notes, my notes this week

1. goto https://www.icloud.com/notes/ and `wait` for the folder list. If a sign-in, 2FA or trust page appears, use `login`.
2. Click "All iCloud" (or "Notes" at the top of the folder list) so every folder's notes are listed, sorted by date edited (the default; if not, use the sort option in the list's menu).
3. `read` the note list for the period the task names (default: last 7 days): title, folder, date, preview. Stop at the first note older than the period.
4. Open the 5 most recently edited and `read` their bodies for anything with a date, a deadline or an unchecked checklist item.
5. Report the notes newest first as bullets: title, folder, date, one-line gist; then a short "open items" list pulled from checklists and to-dos with the note each came from.
