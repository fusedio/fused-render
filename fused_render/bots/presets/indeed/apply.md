# Indeed apply to a job
trigger: apply on indeed, apply to this job, submit my application, indeed apply, apply for the job, easy apply on indeed, easily apply

1. goto the posting (https://www.indeed.com/viewjob?jk=<id>) or search https://www.indeed.com/jobs?q=<title>+<company>&l=<city> and click the matching card. Cloudflare "Additional Verification Required" or a sign-in page → `login`.
2. `read` the description and confirm it is the job the task means: title, company, location, pay. If several postings match, `ask` which one.
3. Check the button. "Apply now" opens Indeed Apply and stays on Indeed. "Apply on company site" leaves Indeed: stop, report the external link, and continue only if the task says to apply on external sites.
4. Click "Apply now" and work through the steps: the resume step (pick the Indeed resume already on the account; never upload a file the task did not name), contact details, then screener questions. Answer only from facts the task or the user's profile gives; if a question needs something you do not have, `ask`.
5. On the "Review your application" step `read` everything shown. Stop before the final "Submit your application" button, show the user exactly what will be sent, and proceed only after approval.
6. Report: job, company, what was submitted (resume name, answers), the confirmation text and the posting link. If approval is refused, report what was filled and leave the application unsubmitted.
