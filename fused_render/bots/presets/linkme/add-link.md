# Linkme add or update a link
trigger: add a link to my bio, update my bio link, put this in my linkme, change the link to, add to link in bio, linkme add, hide the link on my bio, add to my linkme

1. goto https://linkme.bio/dashboard; if a sign-in page, 2FA or captcha appears, use `login`. Open the Links section and `read` the current list so you know the order and whether a block with the same title or URL already exists (then update that one instead of adding a duplicate).
2. Adding: click the add-link / add-block button ("Adicionar link" or "Novo bloco"), choose the plain link block, and type the title and URL exactly as the task gives them. Updating: click the existing block to open its editor and change only the field the task names. Hiding: locate the block's on/off toggle but do not flip it yet.
3. Position: follow the task (default: top). If the block must be dragged, say so in the approval instead of dragging now.
4. Stop before the final Save ("Salvar") or the toggle. Show the user: title, URL, position, on/off, schedule, and what it replaces. Proceed only after approval; this is the single risky action in this playbook.
5. After saving, goto https://linkme.bio/<username>, `read` the page and confirm the block appears where intended; open the link with tab new to confirm it lands on the right URL, then tab close.
6. Report what changed (before and after), the block's position and the public page link. `remember` the add-block button's exact label once you have seen it.
